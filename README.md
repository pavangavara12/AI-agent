# Agentic AI Learning Journey 🚀

## About This Repository

Welcome to my Agentic AI Learning Journey!

This repository documents my daily learning activities, Python notebooks, practical implementations, experiments, and projects while learning Agentic AI.

The journey focuses on building AI-powered applications using Python, Large Language Models (LLMs), LangChain, LangGraph, Groq, and other AI technologies.

Throughout this journey, I use **Sweet Crumbs Home Bakery** as a practical case study to understand how AI agents can solve real-world business problems.

## ▶️ How to Run the Projects

1. Open the required Jupyter Notebook (`.ipynb`).
2. Upload it to Google Colab or open it directly from GitHub in Colab.
3. Install the required Python libraries.
4. Configure the required API keys securely.
5. Run the notebook cells in order.
6. Observe the outputs and test the implementation.

**Security:** Never upload real API keys, passwords, or private credentials to GitHub. Use environment variables or Google Colab Secrets.
